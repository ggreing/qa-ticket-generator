# ADR-0010: Output languages

- Status: Accepted (2026-11-12)
- Relation to the v1 draft: New.
- Spec: `docs/SPEC.ko.md`

## Context

Users are global but the initial audience includes Korean, Japanese and Chinese teams.

## Decision

Default output language `en`; support `ko`, `ja`, `zh-CN` (BCP 47) and accept aliases `kr`, `jp`, `cn`, `zh`. UI strings live in i18n tables; LLM text language is set in the prompt. README ships in the same four languages. Traditional Chinese (`zh-TW`) is planned for v1.1.

## Consequences

- Standards-compliant codes with friendly aliases.

* Four translations to keep in sync.
